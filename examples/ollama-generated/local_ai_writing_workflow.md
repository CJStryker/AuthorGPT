# Chapter 1. Building the Loop

## 1.1 Start Small

A reliable local writing workflow begins with small requests. Ask the model for a title, then an outline, then one section at a time. This keeps context manageable and makes failures recoverable. If the server slows down or returns an empty answer, the writer loses only the current section instead of an entire manuscript. Saving after every completed section turns a fragile generation run into a series of checkpoints. The habit is simple: generate, inspect, save, and continue.

## 1.2 Review Before Expanding

Local models are useful collaborators, but they still need direction. After each draft, check whether the section follows the outline, introduces new information, and avoids repeating earlier paragraphs. If it misses the target length, request a continuation with a clear instruction to add new details rather than restating the same idea. This review loop improves the final book and prevents the model from wandering while the application waits indefinitely for perfect output.
